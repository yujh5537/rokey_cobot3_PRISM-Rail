# 시연 큐시트 v1.0 — 의료 레일 관제 디지털 트윈 (실측 이벤트 로그 기반)

시뮬레이션은 실시간 1:1 (30Hz). 아래 t는 `start` 호출 기준 경과 초 = 발표 중 실제 초.
조작 서비스는 전부 `std_srvs/srv/Trigger` 입니다 (control_core_node.py 제공, 실기 `ros2 service list` 확인 완료).

```
/sim_start   /sim_pause   /sim_reset   /sim_status
/sim_mode_a  /sim_mode_b  /code_crimson  /code_red
```

호출 형식: `ros2 service call <서비스> std_srvs/srv/Trigger`

## 0. 사전 준비 체크리스트 (발표 30분 전)

- [ ] 전원 `ROS_DOMAIN_ID=136` 확인 (`echo $ROS_DOMAIN_ID`)
- [ ] 워크스페이스 빌드 최신 + 새 터미널마다 `source install/setup.bash`
- [ ] 터미널 배치: T1=관제 노드 / T2=서비스 콜 전용 / T3=`ros2 topic echo /order_event` (심사위원용 로그 화면)
- [ ] Isaac Sim 씬 + 브릿지 기동, 캡슐 10대 프림 확인 (C01~C04 대기열, C05~C07 스테이션, C08~C10 디포)
- [ ] UI 대시보드 접속, `/block_state` 수신 확인 (TRANSIENT_LOCAL이라 늦게 켜도 수신됨)
- [ ] ⚠️ mock_core는 반드시 종료 상태 (실코어와 동시 실행 = 이중 발행 사고)
- [ ] 백업 자료 열어두기: 수치 슬라이드, 폭주 그리드락 녹화 영상
