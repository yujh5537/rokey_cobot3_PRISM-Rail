## 5. 선점·주행 규칙 (R1~R10)

| ID | 규칙 |

| R2 | 진입 전 양보: 충돌 블록 미진입 하위 캡슐은 블록 경계 앞 정차 대기. **v3.6.1 노드 셋백**: 정차 지점은 블록 끝이 아니라 **끝 − `node_setback`(0.4m)** — 노드는 통과 캡슐과 공유하는 기하라 끝점 정차 시 씬에서 겹친다(스크린샷 실사로 발견). 재개 승인 시 순간이동 없이 잔여 0.4m 를 주행한 뒤 통과한다 |
| R3 | 물리적 대피: 하위 캡슐은 루프 대피 레인(BB-04b/06c/B2-04b/07b, 각 3대) 또는 빈 지선으로 회피. **v3.6 확장 — 동방향 저속 비켜서기**: 파도가 **뒤에서** 접근하고 내 속도가 파도보다 느리면(P3 0.7 등) 대피 자산으로 비켜 콘보이를 먼저 보낸다. 저속 캡슐을 앞세워 플러시하면 콘보이가 그 속도에 갇히기 때문. P1(2.0 = 파도 동속)과 대피 자산 없는 구간의 P2는 자동 비대상. **v3.6.1 대피 홀드 래치**: 대피한 캡슐은 레인 **중앙(`evac_hold_frac` 0.5)에 정지**하고, 내 레인·다음 본선 블록이 잠금 밖이며 다음 블록에 (자신 제외) 대향 점유자가 없을 때만 재출발한다. 이전에는 대피 후에도 굴러가 레인 끝까지 간 뒤 파도 틈에 재진입을 시도해 **왕복 진동**이 보였다(씬 실사) |
