# 관제 코어 기술 문서 (v1.0 확정판) — A. 관제 코어 (남현지)

> 레포 `docs/관제_기술문서.md` 교체용. 인터페이스 정본은 `interface_schema.json v3.2` 단일 기준.

의료 레일 배송 디지털 트윈의 관제 서브시스템. 병원 2개층 30개 블록 위 캡슐 10대를
30Hz로 관제하며, P0(Code Crimson) 대량수혈 프로토콜의 **우선순위 선점**을 핵심 시연으로 한다.

## 1. 한 문장 요약

> 선착순(FCFS) 관제 대비, 우선순위 선점(PEDD) 관제는 **혈액 콘보이 도착을 7.9% 앞당기고**,
> 동시 폭주 상황에서 FCFS가 빠지는 **정면 그리드락을 대피 기동으로 원천 회피**한다.

## 2. 아키텍처 — 포트·어댑터 3계층

```
[Isaac Sim 씬(B)] ←프림 트랜스폼─ [브릿지(C)] ←/capsule_pose(30Hz)─┐
[웹 대시보드(D)] ←/block_state, /order_event ────────────────────┤
                                            [node.py  (rclpy 어댑터)]
                                            [bridge.py (제어·페이로드, ROS 무관)]
                                            [control_core (관제 엔진, 순수 Python)]
```

- **진실 소스는 관제 코어**: 캡슐 위치(블록id + 진행거리 + 방향 + xyz)를 코어가 계산·발행,
  씬과 UI는 구독만 한다. 좌표 변환 로직은 `geometry.py` 한 곳(발행원 반올림 원칙 포함).
- rclpy 의존부를 어댑터로 격리 → ROS 없이 전 로직 테스트 가능, 통합 장애 시
  "브리지 테스트 통과 여부"로 관제/연동 책임 즉시 분리.

## 3. 3FSM — 상태 기계 3종

| FSM | 상태 | 비고 |
|---|---|---|
| 오더 | CREATED → EN_ROUTE → ARRIVED → DONE | P0는 4캡슐 슈퍼오더 (전원 도착 시 ARRIVED) |
| 캡슐 | DOCKED/QUEUED/STANDBY → MOVING ↔ YIELD_WAIT/EVACUATED/FINISHING → UNLOADING → REMOVED | |
| 블록 | FREE / RESERVED / OCCUPIED | RESERVED = 선점 잠금 또는 진입 예약, `/block_state`로 발행 |

## 4. 알고리즘 4계층

| 계층 | 채택 | 탈락 대안과 이유 |
|---|---|---|
| ① 배차 | PEDD(우선순위→EDD) + 콘보이 슈퍼오더 | 단순 FIFO: 응급 역전 불가 |
| ② 경로 | 정적 경로 테이블 | WHCA*/CBS: 트리형 토폴로지라 경로가 유일 — 탐색할 것이 없음 |
| ③ 교통 제어 | 철도식 폐색: 블록 상호배제 + 차두간격 + **회랑 방향 토큰** + 단방향 | 은행원 알고리즘: 더 복잡하면서 이 구조에선 이득 없음 |
| ④ 긴급 대응 | **ETA 이동 파도 선점** + 3분기 스윕 + 롤링 해제 | 전 경로 일괄 잠금: 원거리 하위 오더까지 과잉 지연(P1 2배 지연 실측) |

### 4-1. 이동 파도(bow-wave) 선점 — 장면 ①②③의 단일 원리

P0 발령 시 콘보이의 **잔여 경로 중 ETA 15초 이내 블록만** 잠근다(파도는 콘보이와 함께
전진, 지나간 블록은 자동 해제). 파도를 만난 하위 캡슐은 3분기로 처리:

1. **양보 (R2/R5)** — 파도 밖에 있으면 진입 보류. 단, 내 위치(블록/회랑)가 상위 경로에
   걸치면 양보 대신 전진해 비운다(제자리 대기가 상위를 막는 역효과 방지).
2. **완주 허용 (R4)** — 파도와 **같은 방향**이면 잠금 블록으로의 탈출 전진(플러시) 허용.
   실측: P1이 파도에 올라타 모드 A보다도 14.2% 빨리 도착.
3. **대피 (R3)** — 파도와 **역방향**이면 ①루프 대피 레인 치환(EVAC_LANE) ②빈 지선 왕복
   회피(EVAC_SPUR, 상위 목적지 지선은 제외) 순으로 회피. 지선 내 저속 후진만 허용(제자리 리버설).

R6(미발령 오더 잠금 제외 — 예지 금지), R8(안전망: 모드와 무관하게 항상 적용).

## 5. 시연 시나리오와 수치 (토폴로지 v3.2 실측, 30Hz, 결정론 검증)

발령: P2=1s, P1=2s, **P0=8s**, P3=10s (P3는 오염 기구 저속 0.7m/s 규정)

| 오더 | 모드 A (FCFS) | 모드 B (선점) | 해석 |
|---|---|---|---|
| **P0 혈액 콘보이 4대** | 51.70 s | **47.60 s** | **−7.9%** — 헤드라인 |
| P1 응급약품 | 30.73 s | **26.37 s** | −14.2%, 완주 허용 효과 |
| P2 항암제 | 24.73 s | 54.60 s | 양보 비용 +29.9s (장면 ④ 대시보드) |
| P3 오염기구 | 41.33 s | 64.23 s | 대피 비용, **장면 ③: B2-04b 대피 레인** |

모드 A 도착 순서는 선착순(P2→P1→P3→P0), 모드 B는 P1→P0→P2→P3 — "중요한 것부터".

## 6. 안전·품질 검증 (테스트 21종)

- **R8 불변식 전수 검사**: 매 틱 30블록 × {용량 초과, 정면 대치, 역주행, 추월, 구간 이탈}
  — 시연·폭주 전 시나리오에서 **위반 0건** (안전은 모드와 무관하게 보장)
- **회귀 기준값 고정**: 기준값 ±0.2s 이탈 시 테스트 실패 → 성능 회귀 즉시 감지.
  컨테이너 측정값 64.23s가 실기 ROS 경로에서 그대로 재현됨(관제 결정론 입증)
- **발행원 반올림**: 전 좌표 소수 4자리 불변식 (부동소수 잔재 재발 방지)

## 7. 엣지케이스와 한계

| 케이스 | 모드 A | 모드 B |
|---|---|---|
| 전 오더 1.5초 내 폭주 | **정면 그리드락** (P3↔콘보이 대치) | 대피 기동으로 **완주**, PEDD 유지 |
| 그리드락 감지 | 20s 무진행 시 **DEADLOCK 이벤트** 자동 통보 (대치 당사자 포함) | 해당 없음 |
| 역방향 배송 vs 콘보이 | — | 지선 대피(EVAC_SPUR) 후 왕복 복귀 완주 |
| Code Crimson 수동 발동 | — | 즉시 출동 / 자동 발령 후 중복 발동은 사유와 함께 거부 / 일시정지 중 발동 지원 |

**설계상 한계 (정직 고지)**: ① 모드 A의 그리드락은 해소가 아니라 감지·통보까지가 범위
(FCFS의 본질적 한계이며, 이것이 선점 관제의 존재 이유) ② 하역 후 회송·디포 재충전은
시연 범위 외 ③ 경로 유일 가정 — 레일 증설 시 계층 ②를 탐색형으로 교체 필요
④ 캡슐 고장 대응 — 고장 캡슐을 EVACUATED 고정으로 두면 폐색 규칙이 해당 블록을
우회 불가 자원으로 처리하고 DEADLOCK 감지가 후속 정체를 통보하는 데까지는 동작하나,
회수 오더 자동 생성은 미구현(향후 과제).

## 8. 인터페이스 (정본: interface_schema.json v3.2)

토픽 `/capsule_pose`(30Hz, BEST_EFFORT) · `/block_state`(변화 시, TRANSIENT_LOCAL) ·
`/order_event`(RELIABLE 50).
서비스: 관제 노드(control_core_node.py)가 **std_srvs/Trigger 8종** 제공
(`/sim_start` … **`/code_crimson`** — 전체 목록은 `ros2 service list`), CLI `ros2 service call`로 조작.
`rail_interfaces` srv 2종(CodeCrimson/SimCommand)은 **deprecated** (Trigger 8종으로 대체, 다음 정리 시 삭제).
씬 프림: 브릿지 내부 매핑으로 `Capsule_01` 형식 사용 [프림 명명 최종 확정: B 확인 대기].
이벤트 어휘: ORDER_RELEASE, ORDER_ARRIVE, YIELD, EVAC_LANE, EVAC_SPUR, FINISH_ALLOWED,
RESUME, CODE_CRIMSON, DEADLOCK, SIM_DONE.
